## Рамки

Оценивается код оригинального Zhabbler, унаследованный форком. Пока не проводились локальный запуск приложения, нагрузочное тестирование, Composer/npm-аудит, тестирование эксплуатации и проверка всех маршрутов/API. Приведённые риски предварительны: обнаруженное в коде ещё не обязательно означает доказанную эксплуатацию.

Пока **не разворачивать в публичном интернете**, не использовать настоящие учётные данные и не открывать регистрацию.

## Дополнительные пункты проверки

- `Web/Models/User.php` и `ZhabblerAPI/User.php`: права доступа, блокировки, раскрытие токенов, публичные ответы API.
- `Web/Models/Posts.php` и `ZhabblerAPI/Posts.php`: сохранение и вывод HTML, авторизация действий, лимиты.
- `Web/Models/Sessions.php` и `ZhabblerAPI/Sessions.php`: независимые пути аутентификации, CSRF, срок жизни и отзыв сеансов.
- `sql/` и `zhabbler-dump.sql`: порядок миграций, целостность данных, тестовые записи.
- `composer.json` и `Web/public/static/package.json`: версии зависимостей; отсутствие lock-файлов проверить отдельно.
- Корень сайта `Web/public` и построение путей в `Utilities/Files.php`: тестировать после установки в изолированном стенде.

## Security Core 0.1.0 — часть 2 (19 ноября 2026)

**Статус:** предварительные исправления внесены в ветку `security-hardening`; проверки PHP-кода прошли на GitHub Actions. Полный аудит и браузерные испытания не завершены.

### Внесённые исправления

- `Utilities/Strings.php`: фильтр ссылок; ограничение адресов пользовательских медиа локальными `/uploads/`; защита от обхода каталогов и подозрительных URL. Удалены бесполезные вызовы `preg_replace`, убрано сетевое чтение изображений при выводе публикаций.
- `Web/Models/Posts.php`: прежде чем выполнить `unlink()`, путь изображения проверяется тем же фильтром локальных файлов.
- `Utilities/Files.php`: импорт изображений по URL **временно отключён**, чтобы убрать SSRF через эту операцию; ограничены размеры загрузок (изображения — 10 МиБ, GIF — 4 МиБ, MP3 — 20 МиБ, видео — 50 МиБ), добавлены проверки файлов и обработка ошибок конвертации; FFmpeg запускается с экранированными путями.
- `Web/public/uploads/.htaccess`: ограничено выполнение серверных скриптов из каталога загрузок, запрещён просмотр списка файлов. Действие правил зависит от настройки Apache, требует проверки на стенде.
- `.github/workflows/security-checks.yml`: PHP 8.3, синтаксис изменённых файлов и проверки на GitHub Actions.

### Не завершено

- **BB-SEC-001 — частично смягчено:** требуется сквозной аудит сохранения и выдачи HTML во всех API, представлениях и шаблонах, проверка старых постов.
- **BB-SEC-003 — сетевой путь отключён:** возвращать загрузку по URL можно только после разработки изолированного загрузчика с проверкой IP/DNS, отключением редиректов и ограничением потока.
- Интеграционные испытания конвертации, реальных загрузок, настроек Apache и разрешений на файлы пока не проводились.
- Сеансы, CSRF, разграничение доступа, WebSocket, шифрование сообщений и исходный `config.neon` **ещё не исправлены**.

**Не включать публичную регистрацию и не объединять ветку с `main` до полноценной проверки.**
